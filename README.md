# croma

## 🚀 Overview
A static e-commerce store prototype inspired by Croma India, built with pure HTML and CSS. This project demonstrates responsive layout, structured content, and modern UI principles without JavaScript.

## 📁 Folder Structure
See above structure for details.

## 💡 Features
- Home page with promotional banners and featured products
- Product listing grid using CSS Flex/Grid
- Product details with specifications and pricing
- Contact form layout (non-functional)
- About page with brand description
- Fully responsive with mobile-first design

## 🛠️ Technologies Used
- HTML5: Markup and structure
- CSS3: Styling, grid/flex layout, transitions

## 🌐 Deployment
### GitHub Pages:
1. Push your project to GitHub.
2. Go to Settings > Pages.
3. Set source to `main` branch, root folder.
4. Visit `https://yourusername.github.io/croma-store-website/`.
